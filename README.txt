NOVA STARTUP WEBSITE — PORTFOLIO DEMO
=====================================

WHAT'S INCLUDED (7 PAGES)
1. index.html     — Home
2. product.html   — Product
3. about.html     — About
4. waitlist.html  — Early-access signup form
5. faq.html       — Frequently asked questions
6. contact.html   — Contact form
7. privacy.html   — Sample privacy policy

DESIGN
- Warm cream, deep purple, coral, lilac and soft yellow palette
- Responsive layout for mobile, tablet and desktop
- Shared navigation and footer
- CSS illustrations / dashboard mockups (no external image files required)
- Mobile navigation menu
- FAQ accordion
- Client-side form validation and success messages

HOW TO OPEN
1. Download and extract nova-startup-website.zip.
2. Open the extracted folder.
3. Double-click index.html to preview in a browser.
4. For best results, use VS Code with the Live Server extension, or upload the folder to GitHub Pages / Netlify.

IMPORTANT DEMO LIMITATIONS
- This is a front-end portfolio demo. Waitlist and contact forms DO NOT send or store data.
- To receive real submissions, connect a backend or a trusted form service (for example, Formspree, Getform, or your own API).
- Replace hello@nova.example and partners@nova.example with real contact details.
- Privacy policy content is sample text and should be reviewed before any real launch.
- “Nova” is a fictional brand concept for portfolio presentation. Check brand/domain availability before using it for a real business.
- Google Fonts load from the internet; if offline, fallback fonts will be used.
